# 🎮 Games Vault Shop Bot

Telegram բոտ՝ խաղային արժույթների և աբոնեմենտների վաճառքի համար (Roblox, Standoff 2, Brawl Stars, PUBG, FC Mobile):

## ✨ Հնարավորություններ
- 🛒 Խաղային արժույթների գնում
- 📸 Վճարման հաստատում սքրինշոթի միջոցով
- 🔐 2FA հաստատում (Authenticator, E-mail, Այլ սարք)
- 👨‍💼 Ադմին վահանակ՝ պատվերների կառավարմամբ
- 📊 Պատվերների վիճակագրություն
- 🚫 Օգտատերերի սև ցուցակ
- 📝 Բոլոր գործողությունների լոգավորում

## 🚀 Տեղադրում
1. Կլոնավորիր ռեպոզիտորիան
2. Տեղադրիր կախվածությունները՝ `pip install -r requirements.txt`
3. Ստեղծիր `.env` ֆայլը փոփոխականներով (տես `.env.example`)
4. Գործարկիր՝ `python gamesvaultshop.py`

## 📝 Միջավայրի փոփոխականներ
- `BOT_TOKEN` - բոտի տոկեն (պարտադիր)
- `ADMIN_ID` - ադմինիստրատորի ID-ն (պարտադիր)
- `ORDER_CHANNEL_ID` - պատվերների ալիքի ID (պարտադիր չէ)
- `SUPPORT_CHANNEL_ID` - աջակցության ալիքի ID (պարտադիր չէ)
- `TELCELL_NUMBER` - Telcell համար (պարտադիր)
- `PORT` - պորտ (լռելյայն՝ 10000)
